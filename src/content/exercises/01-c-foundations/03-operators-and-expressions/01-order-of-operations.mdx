solution: |
  #include <stdio.h>

  int main(void) {
      int a, b, c;
      scanf("%d %d %d", &a, &b, &c);
      int result = a + b * c;
      printf("Result: %d\n", result);
      return 0;
  }
---

Read three integers `a b c` and print the value of `a + b * c`, in the form `Result: 14`.

This is a direct check that you're reading the expression the way the *compiler* does, not strictly left to right:
`*` runs before `+`, exactly like ordinary math. Work out `2 + 3 * 4` by hand before you code anything -- if you get
`20`, re-read the precedence section of the lesson before continuing.
