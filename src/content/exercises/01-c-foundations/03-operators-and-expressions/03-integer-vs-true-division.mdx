hints:
  - "The first line is the easy one: a / b with both still int gives you truncating division directly -- print it with %d."
  - "The second line needs a cast on at least one operand before the division happens, or you'll get the same truncated int result promoted to a double after the fact: (double)a / b."
  - "printf(\"True division: %.2f\\n\", (double)a / b); -- the cast on `a` forces the whole division to happen in floating point."
solution: |
  #include <stdio.h>

  int main(void) {
      int a, b;
      scanf("%d %d", &a, &b);

      printf("Integer division: %d\n", a / b);
      printf("True division: %.2f\n", (double)a / b);
      return 0;
  }
---

Read two integers `a` and `b` and print **both** ways of dividing them: plain truncating integer division on the
first line, and the real (non-truncating) division, rounded to 2 decimal places, on the second.

The first line is just `a / b` -- both operands are already `int`, so it truncates on its own. The second line is
the one to be deliberate about: `a / b` alone would still compute the truncated integer result first and only
convert it to a `double` afterward, by which point the remainder is already gone. You need a cast on at least one
operand -- `(double)a / b` -- to make the division itself happen in floating point, exactly as covered at the end
of the lesson.
