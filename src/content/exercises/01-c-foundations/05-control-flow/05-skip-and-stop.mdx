hints:
  - "Check the multiple-of-3 condition first, with continue, before checking the greater-than-15 condition with break -- for every i this exercise actually reaches, the two conditions never overlap, so the order between them won't change your output, but it keeps the logic reading in the same order as the instructions."
  - "for (int i = 1; i <= n; i++) { if (i % 3 == 0) continue; if (i > 15) break; printf(\"%d\\n\", i); }"
solution: |
  #include <stdio.h>

  int main(void) {
      int n;
      scanf("%d", &n);

      for (int i = 1; i <= n; i++) {
          if (i % 3 == 0) {
              continue;
          }
          if (i > 15) {
              break;
          }
          printf("%d\n", i);
      }
      return 0;
  }
---

Loop from `1` to `n`, applying two different kinds of early exit: `continue` past any multiple of `3` (it's
skipped, but the loop keeps going), and `break` out of the loop entirely the moment `i` exceeds `15` (nothing from
that point on gets printed, or even checked).

Trace the `n = 20` case by hand before running it: multiples of `3` up through `14` get skipped one at a time as
the loop continues normally, but the moment `i` reaches `16`, the loop stops completely -- `17` through `20` are
never printed, and never even reach the multiple-of-3 check, because `break` exits before either happens.
