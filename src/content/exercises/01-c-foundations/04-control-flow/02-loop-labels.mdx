hints:
  - "Check 'divisible by both' first -- if you check 'divisible by 4' first and print+continue, you'll never reach the combined case."
  - "A number is a multiple of both 4 and 7 exactly when it's a multiple of 28 (their least common multiple, since 4 and 7 share no common factors)."
  - "for (int i = 1; i <= n; i++) -- inclusive of n, which is an off-by-one spot to double check."
solution: |
  #include <stdio.h>

  int main(void) {
      int n;
      scanf("%d", &n);
      for (int i = 1; i <= n; i++) {
          if (i % 4 == 0 && i % 7 == 0) {
              printf("AlphaBeta\n");
          } else if (i % 4 == 0) {
              printf("Alpha\n");
          } else if (i % 7 == 0) {
              printf("Beta\n");
          } else {
              printf("%d\n", i);
          }
      }
      return 0;
  }
---

Read one integer `n`, then print the numbers from `1` to `n` inclusive, one per line -- except:

- if the number is a multiple of both 4 and 7, print `AlphaBeta` instead
- if it's a multiple of 4 only, print `Alpha`
- if it's a multiple of 7 only, print `Beta`

This is a `for` loop with an `if`/`else if`/`else` chain inside it, and the classic trap is branch *order*: the
"multiple of both" check has to come first, because a number that's a multiple of 28 is *also* a multiple of 4, so
a naive "check 4 first" chain would report `Alpha` and never reach the combined case.
