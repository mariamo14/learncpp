hints:
  - "5 in binary is 101 -- bit 0 (the rightmost) is 1, bit 1 is 0, bit 2 is 1. Build 1 << position to isolate just that bit, then AND it with n."
  - "if ((n & (1 << position)) != 0) { printf(\"Set\\n\"); } else { printf(\"Clear\\n\"); }"
solution: |
  #include <stdio.h>

  int main(void) {
      unsigned int n;
      int position;
      scanf("%u %d", &n, &position);

      if ((n & (1 << position)) != 0) {
          printf("Set\n");
      } else {
          printf("Clear\n");
      }
      return 0;
  }
---

Read `n` and a bit `position` (0 = least significant bit), and print `Set` or `Clear` depending on that specific
bit's value in `n`.

This is the "check" third of the set/check/clear idiom from the lesson: build a mask with a single `1` bit at
`position` using `1 << position`, `&` it with `n`, and compare the result against `0`. Don't forget the
parentheses around `n & (1 << position)` before comparing with `!=` -- bitwise operators bind looser than
comparisons, exactly as the lesson warns.
