hints:
  - "scanf for a double uses %lf, but printf for a double uses %f -- this asymmetry trips everyone up at least once."
  - "printf(\"%.2f\", x) rounds to 2 decimal places for display; it does not change the value stored in x."
solution: |
  #include <stdio.h>

  int main(void) {
      double a, b, c;
      scanf("%lf %lf %lf", &a, &b, &c);
      double average = (a + b + c) / 3.0;
      printf("Average: %.2f\n", average);
      return 0;
  }
---

Read three floating-point measurements and print their average, rounded to exactly 2 decimal places, in the form:

```
Average: 2.00
```

Two things to watch for. First, `scanf` and `printf` use *different* format specifiers for the same type: reading a
`double` needs `%lf`, but printing one uses `%f` (the `l` is only meaningful to `scanf`, which needs to know how
many bytes to write into). Second, divide by `3.0`, not `3` -- dividing by the integer literal `3` still produces a
correct result here because at least one operand (`a + b + c`) is already a `double`, so the whole expression
promotes to floating-point before the division happens. It's worth being deliberate about it anyway.
