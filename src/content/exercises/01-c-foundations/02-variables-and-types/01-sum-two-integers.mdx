solution: |
  #include <stdio.h>

  int main(void) {
      int a, b;
      scanf("%d %d", &a, &b);
      printf("Sum: %d\n", a + b);
      return 0;
  }
---

Read two integers from standard input, separated by whitespace, and print their sum in exactly this form:

```
Sum: 8
```

This is the smallest possible C program: it exercises variable declaration, `scanf` for input, integer addition,
and `printf` for output. Get comfortable with this round trip -- read, compute, print -- before moving on, because
every exercise in this course is a variation on it.
