solution: |
  #include <stdio.h>

  int main(void) {
      int value, low, high;
      scanf("%d %d %d", &value, &low, &high);

      if (value >= low && value <= high) {
          printf("In range\n");
      } else {
          printf("Out of range\n");
      }
      return 0;
  }
---

Read `value`, `low`, and `high`, and print `In range` if `value` falls within `[low, high]` inclusive, otherwise
`Out of range`.

A tempting but wrong instinct here is to write `low <= value <= high` directly, the way you would on paper. That
actually compiles in C -- but not because C understands chained comparisons. It parses as `(low <= value) <= high`:
the first comparison produces `0` or `1`, and *that* gets compared against `high`, which is almost never what you
meant. Use `&&` to combine two independent comparisons instead.
