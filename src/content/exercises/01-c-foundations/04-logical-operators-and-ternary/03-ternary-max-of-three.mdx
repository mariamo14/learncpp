solution: |
  #include <stdio.h>

  int main(void) {
      int a, b, c;
      scanf("%d %d %d", &a, &b, &c);

      int max = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);
      printf("Max: %d\n", max);
      return 0;
  }
---

Read three integers and print the largest, using a **single expression** built from two ternary operators -- not
an `if`/`else if`/`else` chain.

The trick is nesting: first decide whether `a` or `b` is bigger (a plain two-way ternary), then whichever one wins
that comparison needs to be compared against `c` in turn. That's two ternaries, one nested inside a branch of the
other. Parenthesize generously -- it costs nothing and makes the nesting unambiguous to a reader (including you,
tomorrow).
