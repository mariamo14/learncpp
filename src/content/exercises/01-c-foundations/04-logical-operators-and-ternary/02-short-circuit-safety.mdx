solution: |
  #include <stdio.h>

  int main(void) {
      int a, b;
      scanf("%d %d", &a, &b);

      if (b != 0 && a / b > 1) {
          printf("Yes\n");
      } else {
          printf("No\n");
      }
      return 0;
  }
---

Print `Yes` if `b` is nonzero **and** `a / b > 1`; otherwise print `No`. Some of the test cases set `b` to `0` --
your program has to handle that without crashing, which means the division must never actually execute in that
case.

This only works because of short-circuit evaluation, and only in one specific order: put `b != 0` on the left of
`&&`. If C sees that's false, it skips evaluating `a / b > 1` entirely -- the safety check has to run *first* for
the short-circuit to protect you.
