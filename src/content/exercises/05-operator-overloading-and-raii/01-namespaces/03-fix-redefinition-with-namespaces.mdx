solution: |
  #include <iostream>

  namespace weight {
      double convert(double value) {
          return value * 2.20462;
      }
  }

  namespace distance {
      double convert(double value) {
          return value * 1.60934;
      }
  }

  int main() {
      double kg, miles;
      std::cin >> kg >> miles;
      std::cout << "pounds: " << weight::convert(kg) << std::endl;
      std::cout << "km: " << distance::convert(miles) << std::endl;
      return 0;
  }
---

This has two functions named `convert`, both taking a single `double` -- and unlike Module 4's overloading
exercises, identical parameter types mean the compiler has no way to tell them apart. Submit as-is and read the
"redefinition of `convert`" error before changing anything -- this is the exact class of error from Module 3,
except this time the fix isn't merging duplicate logic, it's separating two functions that were never actually
duplicates, just unluckily same-named.

Wrap each version of `convert` in its own namespace (`weight` and `distance` are reasonable names, but any pair
of distinct names works), and update the two call sites in `main` to qualify each call appropriately.
