solution: |
  #include <iostream>

  namespace finance {
      double applyRate(double principal, double rate) {
          return principal * rate;
      }
  }

  namespace physics {
      double applyRate(double distance, double rate) {
          return distance * rate;
      }
  }

  int main() {
      double a, b;
      std::cin >> a >> b;
      std::cout << "finance: " << finance::applyRate(a, b) << std::endl;
      std::cout << "physics: " << physics::applyRate(a, b) << std::endl;
      return 0;
  }
---

Define `physics::applyRate` alongside the already-complete `finance::applyRate` -- same name, same parameter
types, same formula, living in a different namespace. Without namespaces, this would be a flat redefinition error,
identical to Module 3's `is_even` exercise; with them, both coexist and `main` calls each one unambiguously by its
qualified name.
