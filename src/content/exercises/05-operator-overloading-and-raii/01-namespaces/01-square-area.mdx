solution: |
  #include <iostream>

  namespace geometry {
      double squareArea(double side) {
          return side * side;
      }
  }

  int main() {
      double side;
      std::cin >> side;
      std::cout << "Area: " << geometry::squareArea(side) << std::endl;
      return 0;
  }
---

Define `squareArea` inside the `geometry` namespace, so that `geometry::squareArea(side)` -- already called in
`main` -- computes `side * side`.

This is the smallest possible namespace: one function, called through its qualified name, exactly the same
pattern as `std::cout` you've been writing all along.
