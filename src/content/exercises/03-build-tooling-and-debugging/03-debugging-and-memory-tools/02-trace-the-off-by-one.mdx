solution: |
  #include <stdio.h>

  int main(void) {
      int n;
      scanf("%d", &n);
      int values[100];
      for (int i = 0; i < n; i++) {
          scanf("%d", &values[i]);
      }

      int total = 0;
      for (int i = 0; i < n; i++) {
          total += values[i];
      }
      printf("Total: %d\n", total);
      return 0;
  }
---

This program compiles and runs -- it just returns the wrong total, consistently missing the last element. This is
the exact bug traced in the lesson's annotated debugger transcript: before changing anything, trace `i` and
`total` by hand through every iteration for the sample input (`n = 4`, `values = [1, 2, 3, 4]`), the same way the
transcript watched them converge on the bug.

Once you can see which value never gets added and why the loop stops one iteration early, the fix is a single
character.
