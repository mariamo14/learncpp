solution: |
  #include <stdio.h>

  #define MIN_SCORE 0
  #define MAX_SCORE 100

  int main(void) {
      int score;
      scanf("%d", &score);

      if (score >= MIN_SCORE && score <= MAX_SCORE) {
          printf("In range\n");
      } else {
          printf("Out of range\n");
      }
      return 0;
  }
---

`main` already checks `score` against `MIN_SCORE` and `MAX_SCORE` -- your only job is to `#define` both, to `0`
and `100` respectively, so the file compiles at all.

Notice there's no semicolon and no `=` in a `#define` -- it isn't a C statement, it's a preprocessor directive, and
the compiler never sees `MIN_SCORE` or `MAX_SCORE` as names at all; by the time compilation starts, every
occurrence has already been replaced with the literal number.
