hints:

solution: |
  #include <stdio.h>

  int clamp(int value, int lo, int hi) {
      if (value < lo) return lo;
      if (value > hi) return hi;
      return value;
  }

  int main(void) {
      int value, lo, hi;
      scanf("%d %d %d", &value, &lo, &hi);

      printf("Clamped: %d\n", clamp(value, lo, hi));
      return 0;
  }
---

`clamp` restricts `value` to the range `[lo, hi]`, and it's already implemented correctly. The bug is entirely at
the call site in `main`, which reads all three inputs but only passes two of them through to `clamp`.

Submit this as-is and read the error before fixing it -- it's a different flavor from both previous exercises: not
a syntax error (the code parses fine) and not a link error (the function *is* defined) but a compile-time argument
mismatch, caught because the compiler can see the function's declared signature and this call site in the same
file.
