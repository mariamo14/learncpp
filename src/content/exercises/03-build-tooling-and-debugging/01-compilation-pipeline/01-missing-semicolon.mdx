This program converts a Celsius temperature to Fahrenheit and prints it as `Fahrenheit: 32.0` -- but it doesn't
compile yet. Submit it as-is first and actually read the error message you get back, then fix the program so it
compiles and produces the right output.

This is the exact error from the lesson: a missing semicolon reported one line later than the actual mistake,
because the compiler can't tell a statement was supposed to end until it starts parsing the next one and finds
something that doesn't fit.
