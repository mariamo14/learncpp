  - "Submit this as-is and read the error -- notice it doesn't point at a line in your file the way a syntax error does, and mentions `ld` and 'undefined reference' instead. That's your signal this is a link error, not a compile error: the declaration satisfied the compiler, but no definition exists for the linker to find."
  - "A declaration (`int square(int n);`) is a promise; a definition (`int square(int n) { ... }`) is the promise kept. You need to add the definition."
  - "int square(int n) { return n * n; }"
solution: |
  #include <stdio.h>

  int square(int n);

  int main(void) {
      int n;
      scanf("%d", &n);
      printf("Square: %d\n", square(n));
      return 0;
  }

  int square(int n) {
      return n * n;
  }
---

`main` calls `square(n)`, and `square` is declared above it -- but never *defined* anywhere in the file. Submit
this as-is first and read the error you get: it will look nothing like the syntax errors from the previous
exercise, because this program compiles just fine. It fails one stage later, at link time.

Fix it by adding `square`'s definition (it should return `n * n`) anywhere in the file below its declaration.
