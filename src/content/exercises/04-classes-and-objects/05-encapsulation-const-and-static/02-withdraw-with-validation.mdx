solution: |
  #include <iostream>

  class BankAccount {
  public:
      BankAccount(double startingBalance) : balance(startingBalance) {
      }

      double getBalance() const {
          return balance;
      }

      void withdraw(double amount) {
          if (amount > balance) {
              std::cout << "Rejected" << std::endl;
              return;
          }
          balance -= amount;
      }

  private:
      double balance;
  };

  int main() {
      double start, amount;
      std::cin >> start >> amount;
      BankAccount acc(start);
      acc.withdraw(amount);
      std::cout << "Balance: " << acc.getBalance() << std::endl;
      return 0;
  }
---

Complete `withdraw` so it refuses to overdraw the account: if `amount` is more than the current `balance`, print
`Rejected` and leave `balance` untouched; otherwise, subtract `amount` normally.

This is what `private` data was for: because nothing outside `BankAccount` can touch `balance` directly, `withdraw`
is the *only* path that can change it, which means it's the one place capable of enforcing this rule at all. Direct
field access (as if `balance` were `public`) could never have stopped an overdraw -- there'd be no function in the
way to say no.
