solution: |
  #include <iostream>

  class BankAccount {
  public:
      BankAccount(double startingBalance) : balance(startingBalance) {
      }

      double getBalance() const {
          return balance;
      }

  private:
      double balance;
  };

  int main() {
      double start;
      std::cin >> start;
      BankAccount acc(start);
      std::cout << "Balance: " << acc.getBalance() << std::endl;
      return 0;
  }
---

`balance` is `private` -- `main` has no way to read it directly. Add a `const` member function `getBalance` that
returns it, giving `main` a controlled, read-only way to ask an account what it holds.

Mark it `const`: it only reads `balance`, never changes it, so it should be usable even on an account you only
have const (read-only) access to.
