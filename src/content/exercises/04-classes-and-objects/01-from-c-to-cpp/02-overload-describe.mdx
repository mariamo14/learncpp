solution: |
  #include <iostream>
  #include <iomanip>

  void describe(int n) {
      std::cout << "Integer: " << n << std::endl;
  }

  void describe(double x) {
      std::cout << std::fixed << std::setprecision(2) << "Double: " << x << std::endl;
  }

  int main() {
      int i;
      double d;
      std::cin >> i >> d;
      describe(i);
      describe(d);
      return 0;
  }
---

Complete both overloads of `describe` -- one for `int`, one for `double` -- each printing its argument with a
different label and (for the `double` version) a fixed 2-decimal-place format.

`main` calls `describe` twice, once with an `int` argument and once with a `double` one, and never says which
version it means -- the compiler figures that out from each argument's type, at compile time, the same way the
lesson's `add` example did. Notice `std::setprecision(2)` only needs to be sent to `cout` once, inside the `double`
overload -- it stays in effect for that stream from then on.
