solution: |
  #include <iostream>
  #include <string>

  int main() {
      std::string name;
      std::cin >> name;

      std::string greeting = "Hello, " + name + "! Welcome.";
      std::cout << greeting << std::endl;
      return 0;
  }
---

Read a name and print a greeting built by concatenating string pieces with `+`, in the exact form
`Hello, Ada! Welcome.`

Compare this to how much bookkeeping `strcat` needed in Module 2 -- a correctly-sized destination buffer declared
up front, `strcat` never checking whether it actually fit. `std::string`'s `+` handles all of that internally; you
just describe the string you want.
