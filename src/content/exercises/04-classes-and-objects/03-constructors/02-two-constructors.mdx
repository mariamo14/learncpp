solution: |
  #include <iostream>

  class Temperature {
  public:
      double degrees;

      Temperature() : degrees(0) {
      }

      Temperature(double d) : degrees(d) {
      }
  };

  int main() {
      Temperature freezing;
      Temperature custom(37.5);

      std::cout << "freezing = " << freezing.degrees << std::endl;
      std::cout << "custom = " << custom.degrees << std::endl;
      return 0;
  }

Give `Temperature` two constructors: a default one that sets `degrees` to `0`, and one that takes a starting value.
`main` creates one object each way -- `Temperature freezing;` (no arguments) and `Temperature custom(37.5);` (one
argument) -- and both need to work.

This is the same overload-resolution idea from this module's first lesson, applied to constructors specifically:
the compiler picks which constructor runs based on how many arguments the object is created with.
