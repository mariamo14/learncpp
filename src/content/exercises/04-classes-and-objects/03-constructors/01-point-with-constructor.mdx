solution: |
  #include <iostream>

  class Point2D {
  public:
      double x;
      double y;

      Point2D(double px, double py) : x(px), y(py) {
      }
  };

  int main() {
      double a, b;
      std::cin >> a >> b;
      Point2D p(a, b);
      std::cout << "x = " << p.x << ", y = " << p.y << std::endl;
      return 0;
  }
---

Add a constructor to `Point2D` that takes `x` and `y` as arguments and initializes the object's members from them,
using the member initializer list -- not assignment in the body.

`main` already calls `Point2D p(a, b);` -- your only job is making that constructor exist. Parameter names `px`/`py`
(rather than `x`/`y`) sidestep needing `this->` here, exactly as the lesson noted -- that only becomes necessary
once a parameter shares a member's exact name.
