solution: |
  #include <iostream>
  #include <string>

  class Resource {
  public:
      std::string name;

      Resource(std::string n) : name(n) {
          std::cout << "Created: " << name << std::endl;
      }

      ~Resource() {
          std::cout << "Destroyed: " << name << std::endl;
      }
  };

  int main() {
      Resource a("first");
      Resource b("second");
      Resource c("third");
      return 0;
  }
---

Declare three `Resource` objects, in order, named `"first"`, `"second"`, and `"third"` -- and nothing else.
You're not writing any destruction logic at all here; the expected output is entirely a consequence of the rule
from the lesson: objects sharing a scope are destroyed in the exact reverse of their construction order. Declare
them in the order given and let that rule do the rest.
