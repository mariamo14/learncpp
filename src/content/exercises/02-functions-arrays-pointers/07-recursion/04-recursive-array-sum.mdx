solution: |
  #include <stdio.h>

  int array_sum(const int *arr, int n) {
      if (n == 0) {
          return 0;
      }
      return arr[0] + array_sum(arr + 1, n - 1);
  }

  int main(void) {
      int n;
      scanf("%d", &n);
      int values[100];
      for (int i = 0; i < n; i++) {
          scanf("%d", &values[i]);
      }
      printf("Sum: %d\n", array_sum(values, n));
      return 0;
  }

Sum the first `n` elements of `arr` recursively -- the same problem as this module's very first "Array Sum"
exercise, this time without a loop.

The recursive step reuses two ideas from earlier in this module at once: `arr[0]` peels off the first element (an
ordinary array index), and `arr + 1` -- pointer arithmetic -- produces a pointer to "the array starting one
element later," which paired with `n - 1` describes exactly the remaining elements. `array_sum(arr + 1, n - 1)` is
a completely ordinary recursive call on a smaller version of the same problem; it just happens that "smaller" here
means "starting one element further into the same block of memory," not a smaller number passed by value.
