hints:
  - "Inside double_value, `value` is a pointer -- `*value` is the int it points to. You want to change that int, not the pointer."
  - "*value = *value * 2; reads through the pointer, doubles the result, and writes it back through the same pointer."
solution: |
  #include <stdio.h>

  void double_value(int *value) {
      *value = *value * 2;
  }

  int main(void) {
      int n;
      scanf("%d", &n);
      double_value(&n);
      printf("Doubled: %d\n", n);
      return 0;
  }
---

Complete `double_value` so that it doubles, **in place**, the `int` its pointer parameter points to. `main` is
already written to read `n`, call `double_value(&n)`, and print the result -- you're only filling in the function
body.

This is the smallest possible out-parameter: no return value at all, just a pointer the function writes through.
If you find yourself trying to `return` something from `double_value`, stop -- the whole point of this exercise is
modifying the caller's variable through its address instead.
