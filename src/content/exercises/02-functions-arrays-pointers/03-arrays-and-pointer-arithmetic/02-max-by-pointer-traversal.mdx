solution: |
  #include <stdio.h>

  int max_value(const int *arr, int length) {
      int best = *arr;
      for (const int *p = arr; p < arr + length; p++) {
          if (*p > best) {
              best = *p;
          }
      }
      return best;
  }

  int main(void) {
      int n;
      scanf("%d", &n);
      int values[100];
      for (int i = 0; i < n; i++) {
          scanf("%d", &values[i]);
      }
      printf("Max: %d\n", max_value(values, n));
      return 0;
  }
---

Implement `max_value` to return the largest element of the array, walking it with **pointer arithmetic**
(`arr + i` / `*p`-style traversal) instead of `arr[i]` indexing -- the point of this exercise is to make the
`scores[i] == *(scores + i)` equivalence from the lesson feel natural to write, not just to read.

`arr` here is a `const int *`, not `int[]` -- this is the "array decays to a pointer" fact from the lesson made
visible in a function signature: once an array is passed as an argument, the parameter really is just a pointer
(plus, by convention, an explicit `length` alongside it, since `sizeof` can't recover the original array's size
from inside the function).
