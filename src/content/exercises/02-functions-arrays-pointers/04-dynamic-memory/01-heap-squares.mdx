solution: |
  #include <stdio.h>
  #include <stdlib.h>

  int main(void) {
      int n;
      scanf("%d", &n);

      int *squares = malloc(n * sizeof(int));
      if (squares == NULL) {
          return 1;
      }

      for (int i = 0; i < n; i++) {
          squares[i] = i * i;
      }

      for (int i = 0; i < n; i++) {
          printf("%d", squares[i]);
          if (i < n - 1) {
              printf(" ");
          }
      }
      printf("\n");

      free(squares);
      return 0;
  }
---

Read `n`, `malloc` an array of `n` ints on the heap, fill it with the squares `0*0, 1*1, 2*2, ...`, print them
space-separated on one line, and `free` the array.

This is deliberately the same shape as earlier array exercises -- the only new part is that the array's storage
comes from `malloc` instead of being declared with a fixed compile-time size like `int values[100]`. Everything
else (indexing, looping, printing) works identically once you have the pointer back from `malloc`.
