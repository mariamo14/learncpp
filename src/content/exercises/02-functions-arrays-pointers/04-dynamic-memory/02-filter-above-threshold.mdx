solution: |
  #include <stdio.h>
  #include <stdlib.h>

  int main(void) {
      int n, threshold;
      scanf("%d %d", &n, &threshold);

      int *values = malloc(n * sizeof(int));
      if (values == NULL) {
          return 1;
      }
      for (int i = 0; i < n; i++) {
          scanf("%d", &values[i]);
      }

      int printed = 0;
      for (int i = 0; i < n; i++) {
          if (values[i] > threshold) {
              if (printed) {
                  printf(" ");
              }
              printf("%d", values[i]);
              printed = 1;
          }
      }
      printf("\n");

      free(values);
      return 0;
  }
---

Read a count `n`, a `threshold`, and then `n` integers into a heap-allocated array (all done for you). Print only
the elements strictly greater than `threshold`, space-separated, in their original order -- an empty line if none
qualify.

The one wrinkle beyond straightforward filtering: since you don't know in advance how many elements will qualify,
"print a space between elements" can't be based on the loop index the way earlier exercises' "print the whole
array" code could (`if (i < n - 1)`). Track whether you've already printed something instead, and use *that* to
decide whether to print a leading space before the next qualifying value.
