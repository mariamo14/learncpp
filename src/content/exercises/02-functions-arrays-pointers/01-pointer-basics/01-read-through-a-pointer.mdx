solution: |
  #include <stdio.h>

  int main(void) {
      int x;
      scanf("%d", &x);
      int *p = &x;

      printf("Value: %d\n", x);
      printf("Through pointer: %d\n", *p);
      return 0;
  }
---

`p` already points at `x` (that's what `int *p = &x;` set up). Print `x`'s value two ways: directly by name, and
by dereferencing `p`. They should always match -- `*p` and `x` refer to the exact same box in memory, just spelled
differently.

This exercise doesn't ask you to change anything yet -- it's just confirming, with real input instead of a fixed
example, that reading through a pointer really does give you back the pointee's value.
