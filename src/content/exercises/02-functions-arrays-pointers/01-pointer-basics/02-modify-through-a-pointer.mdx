hints:
  - "*p = *p + amount; reads the current value through the pointer, adds amount, and writes the result back through the same pointer -- x itself is never mentioned in this line."
  - "*p += amount; is the same thing, shortened -- same as x += amount; would be, just going through the pointer instead of the name."
solution: |
  #include <stdio.h>

  int main(void) {
      int x, amount;
      scanf("%d %d", &x, &amount);
      int *p = &x;

      *p += amount;
      printf("Result: %d\n", x);
      return 0;
  }
---

This time, actually change `x` -- but only through `p`, never by writing `x` on the left side of an `=`. Add
`amount` to it using `*p`, then print `x`'s new value (printing `x` directly at the end is fine; the requirement is
only about how you *change* it).

This is the write half of the reading you did in the last exercise, and it's the exact mechanic the next lesson
wraps inside a function: a piece of code that doesn't own a variable directly can still reach in and change it, as
long as it has that variable's address.
