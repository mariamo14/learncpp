solution: |
  #include <stdio.h>

  int distance(const int *a, const int *b) {
      return (*a > *b) ? (*a - *b) : (*b - *a);
  }

  int main(void) {
      int x, y;
      scanf("%d %d", &x, &y);
      printf("Distance: %d\n", distance(&x, &y));
      return 0;
  }
---

`distance` takes two `const int *` parameters and returns how far apart the two values are -- always
nonnegative, regardless of which one is larger.

The ternary operator from Module 1 fits this exactly: `(*a > *b) ? (*a - *b) : (*b - *a)` subtracts the smaller
from the larger either way, so the result can never come out negative. Both parameters are `const` for the same
reason as the previous exercise -- this function reads two values and produces a new one; it never needs to write
through either pointer.
