tests:

    stdin: "7"

  - name: "negative"

    hidden: true
hints:
  - "const only restricts writing through p -- reading *p to print it is completely unaffected."
  - "printf(\"Value: %d\\n\", *p);"
solution: |
  #include <stdio.h>

  void describe(const int *p) {
      printf("Value: %d\n", *p);
  }

  int main(void) {
      int n;
      scanf("%d", &n);
      describe(&n);
      return 0;
  }
---

Complete `describe` so it prints the value `p` points to, in the form `Value: 7`. `p`'s type is `const int *` --
you're only ever reading through it here, so this should feel identical to dereferencing any other pointer; `const`
just makes the "read-only" intent explicit and compiler-checked.
