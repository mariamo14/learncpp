solution: |
  #include <stdio.h>

  int main(void) {
      char word[100];
      scanf("%99s", word);

      int count = 0;
      for (int i = 0; word[i] != '\0'; i++) {
          char c = word[i];
          if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u' ||
              c == 'A' || c == 'E' || c == 'I' || c == 'O' || c == 'U') {
              count++;
          }
      }
      printf("Vowels: %d\n", count);
      return 0;
  }
---

Count how many characters in `word` are vowels (either case), and print the count. This combines two things from
earlier in the course: walking a string until its null terminator (this lesson), and comparing a `char` against
several specific values (Module 1's `char`-as-small-integer coverage) -- there's no shortcut around listing out
all ten possibilities (5 letters × 2 cases) explicitly.
