solution: |
  #include <stdio.h>

  int my_strlen(const char *s) {
      int count = 0;
      while (s[count] != '\0') {
          count++;
      }
      return count;
  }

  int main(void) {
      char word[100];
      scanf("%99s", word);
      printf("Length: %d\n", my_strlen(word));
      return 0;
  }

Implement your own version of `strlen` -- count the characters in `s` up to, but not including, its null
terminator. Don't call the real `strlen`; the point of this exercise is the loop itself, which every other string
exercise in this lesson builds on.

`s` is `const char *` for the same reason you saw pointer parameters marked `const` in the last lesson: this
function only reads through `s`, so its signature should say so.
