solution: |
  #include <stdio.h>
  #include <string.h>

  int main(void) {
      char word[100];
      scanf("%99s", word);

      int len = strlen(word);
      int left = 0, right = len - 1;
      while (left < right) {
          char temp = word[left];
          word[left] = word[right];
          word[right] = temp;
          left++;
          right--;
      }

      printf("%s\n", word);
      return 0;
  }
---

Reverse `word` in place, character by character -- the exact same converging two-pointer/two-index technique used
to reverse an int array earlier in this module, adapted to a string: find the length with `strlen`, swap the first
and last characters, then the second and second-to-last, and so on until the two indices meet or cross.

The null terminator itself never needs to move -- it's already sitting in the right place, one past the last real
character, before and after the reversal. Only the `len` characters *before* it get swapped.
