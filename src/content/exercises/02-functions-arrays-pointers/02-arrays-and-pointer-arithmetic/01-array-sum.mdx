solution: |
  #include <stdio.h>

  int main(void) {
      int n;
      scanf("%d", &n);
      int values[100];
      for (int i = 0; i < n; i++) {
          scanf("%d", &values[i]);
      }

      int sum = 0;
      for (int i = 0; i < n; i++) {
          sum += values[i];
      }
      printf("Sum: %d\n", sum);
      return 0;
  }
---

Read a count `n`, then `n` integers into the `values` array (already done for you), and print their sum in the
form `Sum: 10`.

This is the array-indexing warm-up before the next two exercises push into pointer traversal. `values[i]` and
`*(values + i)` compute the exact same address, as covered in the lesson -- use whichever reads more naturally
here; you'll be asked to use the pointer form explicitly in the next exercise.
